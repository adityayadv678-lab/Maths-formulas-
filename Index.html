आज का विशेष सूत्र (Formula of the Day)

अगला सूत्र अपडेट: 14 घंटे बाद
श्रीधराचार्य सूत्र (Quadratic Formula) High Exam Yield ★★★
Class 10 & 11 Core
द्विघात सूत्र का मानक रूप
x = -b ± √b² - 4ac 2a
मानक रूप (Standard Form): ax² + bx + c = 0 (जहाँ a ≠ 0)

व्याख्या: यह सूत्र द्विघात समीकरण ax² + bx + c = 0 के मूल (roots / शून्यक) निकालने के लिए प्रयोग किया जाता है। इसे प्राचीन भारतीय गणितज्ञ श्रीधराचार्य द्वारा प्रतिपादित किया गया था।

a

x² का गुणांक (Coefficient)

b

x का गुणांक (Coefficient)

c

अचर पद (Constant term)

D = b² - 4ac

विवेचक (Discriminant)

व्यावहारिक उदाहरण (Worked Example) हल सहित
प्रश्न (Problem):
2x² - 7x + 3 = 0
के मूल (roots) ज्ञात कीजिए।
1
गुणांक पहचानें:
a = 2, b = -7, c = 3
2
विवेचक (D) निकालें:
D = (-7)² - 4(2)(3) = 49 - 24 = 25
चूंकि D > 0, मूल वास्तविक एवं भिन्न होंगे।
3
सूत्र में मान रखें:
x = [ -(-7) ± √25 ] / 2(2)
x = (7 ± 5) / 4
अंतिम मूल (Final Roots):
x = 3 अथवा x = 1/2
tips_and_updates D < 0 होने पर मूल सम्मिश्र (Complex) होते हैं।

बीजगणित (Algebra) के आवश्यक सूत्र

इस श्रेणी के सभी सूत्र देखें arrow_forward
सर्वसमिका 1 NCERT Cl-9/10
(a + b)² = a² + 2ab + b²

दो पदों के योग का वर्ग। इसका उपयोग बीजगणितीय प्रसार एवं गुणनखंडन में होता है।

Expanded Identity
वर्गों का अंतर NCERT Cl-9/10
a² - b² = (a - b)(a + b)

दो पूर्ण वर्गों का घटाव उनके अंतर व योग के गुणनफल के बराबर होता है।

Difference of Squares
घनों का योग सर्वसमिका NCERT Cl-9/11
a³ + b³ = (a + b)(a² - ab + b²)

घन सर्वसमिका जो उच्च कोटि बहुपदों के मूल ज्ञात करने में काम आती है।
